# Direction Artistique - CliCom

## Principes Généraux
- **Clarté** : communication simple et directe
- **Confiance** : visuels rassurants et professionnels
- **Proximité** : ancrage local suisse romand

## Pages Stratégiques

### Page d'Accueil (Hero)
- **Intention** : "Simplifiez votre gestion administrative"
- **Composition** : visuel d'équipe détendue + interface simplifiée
- **CTA** : "Découvrir la solution" ou "Obtenir une démo"
- **Distinctif** : pas de hero générique, scène de bureau moderne

### Page Solution
- **Intention** : montrer la valeur concrète
- **Composition** : bénéfices en colonnes + témoignages
- **Distinctif** : démonstration visuelle de l'interface

### Page À Propos
- **Intention** : humaniser la marque
- **Composition** : photo équipe, valeurs, engagement local
- **Distinctif** : ancrage suisse romand clairement affiché

### Page Contact/Demo
- **Intention** : faciliter le contact
- **Composition** : formulaire simple + engagement de réponse
- **Distinctif** : mention "PME romandes, on vous comprend"

## Typographie
- Primaire : Inter (lisible, moderne)
- Secondaire : Playfair Display (élégant, pour titres)

## Palette de Couleurs
- Primaire : Bleu professionnel (#1a56db)
- Secondaire : Vert confiance (#059669)
- Accent : Orange chaleureux (#ea580c)
- Neutres : Gris clair (#f3f4f6), Blanc, Gris foncé

## Rythme et Layout
- Espacement généreux pour la lisibilité
- Sections en alternance : texte/image, image/texte
- Cartes avec icônes pour les bénéfices
- Animations subtiles (fade in, hover)
